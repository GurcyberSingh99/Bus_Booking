# Pipeline evidence

The public workflow history is available at [GitHub Actions](https://github.com/GurcyberSingh99/Bus_Booking/actions).

The first published run for commit `a5d92ed` failed while publishing to GHCR. The later run `42785914371` exposed a formatting failure because the monorepo root Prettier config was missing from the initial isolated local check. The formatter now uses the real config. Run `42786747455` also found critical `CVE-2026-111497` in inherited `brotli-libs 1.2.0-r1`; the frontend image now installs fixed `brotli-libs 1.2.1-r0`, and local Trivy reports zero critical findings. Final Actions run [42788332823](https://github.com/GurcyberSingh99/Bus_Booking/actions/runs/42788332823) passed backend/frontend checks, source and image scans, and GHCR publication. The Ubuntu deployment job was skipped because production deployment is opt-in and no VM environment is configured. CI reports install, Prisma generation, migration/seed, formatting, lint, static analysis and API tests separately; it has explicit `packages: write` permissions, OCI source labels and pinned Ubuntu 24.04 runners.

On pull requests, the workflow runs quality/security/image-build jobs but does not publish images or deploy. Main pushes publish immutable `sha-<12>` and `latest` tags; `v*` tags publish version and SHA tags. The deployment job remains opt-in and requires the production environment configuration in [DEPLOYMENT.md](../DEPLOYMENT.md).
